# TARKENSO Broadcast — голосовые объявления (BROADCAST-01)

Система глобального вещания через штатный PlayAudioStreamForPlayer, **без клиентского голосового плагина**. Администратор 5–6 уровня в режиме Duty может начать эфир на 120 секунд. Основатель Veyran обладает правом приоритета. Микрофон передаёт звук через веб-студию; сервер FFmpeg кодирует его в MP3 64 кбит/с и публикует в Icecast.

## Статус реализации

Это исходники. Для работоспособности ещё необходимы настроенные Icecast, FFmpeg, Node.js 20+, домены, HTTPS-сертификаты и тестирование в настоящем клиенте GTA/open.mp. Вызов PlayAudioStreamForPlayer подтверждает только отправку клиенту команды, но не фактическое декодирование звука или доступность живого mount. **Сначала убедитесь, что браузер публикует звук и что HTTPS-поток слышен, затем включайте игровой эфир.**

Обычные игровые звуки GTA не приглушаются. Заменяется только поток от PlayAudioStreamForPlayer (в том числе радио и гоночная музыка). После эфира радио и музыка гонки перезапускаются; восстановление точной позиции композиции не поддерживается. Кассета сюжетного пролога не возобновляется автоматически.

## Инфраструктура

1. Установить Icecast2 и FFmpeg с libmp3lame. Icecast source mount: localhost:8000/live.mp3, с отдельным source-password.
2. Через HTTPS-прокси опубликовать аудио как https://audio.tarkenso.ru/live.mp3 (proxy_pass на Icecast, без буферизации).
3. Через HTTPS-прокси опубликовать веб-студию как https://broadcast.tarkenso.ru (proxy_pass на localhost:3471, Upgrade WebSocket для /ingest, read timeout не меньше 140 секунд).
4. Установить Node.js 20+ и в services/broadcast выполнить npm install, npm run check, npm start с секретами из переменных окружения (пример в .env.example).
5. Запускать шлюз и FFmpeg под отдельным непривилегированным пользователем, с лимитами ресурсов. Не публиковать порт Node и пароль source в интернете.

Для веб-студии нужен HTTPS и Chrome/Edge с поддержкой WebM/Opus. В настройках BROADCAST_PUBLIC_ORIGIN указать точно https://broadcast.tarkenso.ru (без завершающего слеша), ICECAST_HOST по умолчанию 127.0.0.1, ICECAST_PORT — 8000. Ключ BROADCAST_ADMIN_TOKEN — отдельный случайный секрет минимум 32 байта, не игровой пароль. WebSocket ограничен одной сессией, до двух минут, требует авторизационную Secure/HttpOnly cookie и точное совпадение Origin. Пароль Icecast никогда не отправляется браузеру.

## Конфигурация open.mp

Создать scriptfiles/broadcast.cfg, содержимое — **одна строка**:

    https://audio.tarkenso.ru/live.mp3

Без дополнительных строк, параметров запроса, логинов и паролей. Допускаются лишь URL на https://audio.tarkenso.ru/. Некорректный/отсутствующий файл отключает функцию; требуется перезапуск сервера для перечитывания.

## Использование

1. Администратор включает режим /aduty.
2. Открывает https://broadcast.tarkenso.ru, вводит веб-ключ и включает микрофон.
3. Проверяет, что источник Icecast начал вещание, затем в игре выполняет /broadcast start или выбирает «Начать» в меню /broadcast.
4. Все авторизованные игроки получают поток в GTA. Остановка: /broadcast stop в игре и «Остановить микрофон» в веб-студии.
5. /broadcast status показывает текущего ведущего и оставшееся время.

Действует один глобальный эфир, максимум 120 секунд, перерыв 300 секунд между началами. Veyran может прервать чужой эфир, остальные — только собственный. При отключении ведущего, выходе из Duty, потере уровня или истечении лимита эфир завершается. Старт требует успешной записи административного аудита; при сбое журнала действие отклоняется.

## Тесты перед развёртыванием

- Уровень 4, игрок и Duty OFF не должны запускать эфир; при отсутствии broadcast.cfg — отказ.
- Во время эфира нельзя запускать /play и заменять звук гонкой или магнитофоном; после остановки радио/гоночный трек восстанавливаются.
- Игрок, подключившийся посреди эфира, должен услышать голос.
- Проверить два одновременных эфира, приоритет основателя, лимит, cooldown, отключение ведущего.
- Проверить реальное воспроизведение HTTPS MP3 в игровом клиенте, задержку, стабильность и восстановление после обрыва звука. На старых GTA-клиентах возможны TLS-ограничения.
- Проверить отказ доступа к веб-студии без ключа, ограничение неверных попыток и запрет другого Origin.

## Ограничения MVP и следующий этап

В игровом сервере и веб-студии сейчас **два разных уровня доступа**: роль 5+ подтверждает Pawn, а веб-страница защищена отдельным секретом, который следует выдавать только уполномоченным администраторам. В дальнейшем нужен одноразовый обмен токеном между игровым аккаунтом и веб-студией через MariaDB, а также health-check Icecast до отправки потока игрокам, чтобы исключить пустое вещание. Сейчас разрыв внешнего источника сам по себе не останавливает игровое объявление до /broadcast stop или тайм-аута.

Новых таблиц MariaDB для текущего MVP нет, миграции существующих аккаунтов не требуются.
