# TARKENSO — СИГНАЛ 03:17 / Номер 17
## Кассета «Контур / 03:17». Сценарий озвучки, версия 1

Ориентир: 40–55 секунд. По-русски, без музыкальной подложки.
Атмосфера: старый кассетный магнитофон; близкий монофонический голос,
слегка просевшая скорость ленты, шум, механические щелчки.
Не делать слова нечитаемыми из-за шумов.

### Рекомендации по продакшену

- **Нора:** молодой живой голос, узнаваемый для будущих эпизодов.
  Оставить естественное дыхание; без пафоса и крика.
- **Архив:** сухой официальный голос, небольшой эффект телефонной полосы.
  Не делать голос роботизированным полностью.
- **Экспорт:** MP3, 128–192 kbps, 44.1 kHz, mono. Проверить слышимость слов.
- **Финальная обработка:** детонация ±1%, умеренный tape hiss, мягкие
  щелчки, мягкий low-pass; не клиппировать пики.
- **Права:** использовать свою запись или разрешённую актёрами/TTS озвучку,
  и собственные/лицензированные звуковые эффекты.

### Встраивание в open.mp

1. Разместить готовый файл как прямую ссылку, например
   `https://audio.tarkenso.ru/story/room17-cassette.mp3`.
   Это **пример пути**, файл ещё не опубликован.
2. На сервере создать `scriptfiles/story_tape.cfg`; единственная строка —
   прямой HTTPS URL к MP3 или OGG на `tarkenso.ru` или
   `audio.tarkenso.ru` (без редиректов на авторизацию).
3. Перезапустить игровой режим, чтобы он перечитал URL.
4. Подойти к кассете на этапе 2, нажать левый ALT, затем PLAY.
   После прослушивания выбрать «Забрать кассету».
5. Если файл не задан, сохраняется текстовая версия сцены без аудио;
   прогресс игры не блокируется.

**Важно:** успешный результат функции PlayAudioStreamForPlayer означает
отправленную клиенту команду, но не подтверждает, что браузер/клиент
загрузил и декодировал аудио. Проверять в реальном игровом клиенте.
