# Настройка плейлиста гонок

config/race_playlist.example.cfg — шаблон из шести строк. Для включения
создайте scriptfiles/race_playlist.cfg: каждая строка имеет вид
`duration_seconds|https://audio.tarkenso.ru/filename.mp3`.
Разрешены длительности 45–1800 секунд, прямые .mp3/.ogg на tarkenso.ru либо
audio.tarkenso.ru, без пробелов и запрещённых управляющих символов.
Все шесть строк должны быть корректны; лишняя строка, отсутствующий или
повреждённый файл отключает пользовательский список целиком. Тогда гонки
используют резервные композиции из race_audio.inc, а не блокируются.

Метаданные шести выбранных записей и исполнителей находятся в
race_playlist.inc. Наличие записи в этом списке не означает права на публичное
воспроизведение. Оператор должен самостоятельно получить разрешение и разместить
разрешённые файлы; HTML-страницы музыкальных сервисов не являются прямым потоком.

Проверить в GTA корректный список, отсутствие файла, неверную длительность,
недопустимый домен, лишнюю строку, смену треков, /raceaudio playlist и off.
Проверка формата в Python не подтверждает сетевое воспроизведение клиентом.
