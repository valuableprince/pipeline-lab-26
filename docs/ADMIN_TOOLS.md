# Административные утилиты — Tarkenso RPG

Реализованы для действующей версии Pawn/open.mp с MariaDB. Команды регистрируются через Pawn.CMD, права проверяются сервером; для всех нужен авторизованный администратор и включённый `/aduty`.

| Команда | Доступ | Поведение |
| --- | --- | --- |
| `/ahelp` | уровень 1+ | Показывает только команды доступных разрешений и статус Founder / Event Team |
| `/check ID` | уровень 1+ | Имя, ID, уровень, опыт, здоровье, броня, деньги, ранг администрации, организация, виртуальный мир, интерьер и активная блокировка чата |
| `/heal ID` | уровень 2+ | Восстанавливает здоровье до 100 HP |
| `/armour ID 0-100` | уровень 2+ | Устанавливает броню в заданном диапазоне |
| `/fixveh [ID]` | уровень 2+ | Ремонт транспортного средства по ID или своего текущего |
| `/flip [ID]` | уровень 2+ | Поднимает и выравнивает автомобиль по ID или свой текущий |

## Защита и аудит

- Все изменения характеристик и транспорта требуют включённого Duty; все чувствительные команды (`/check`, `/heal`, `/armour`, `/fixveh`, `/flip`) проверяют возможность записи аудита **до** выполнения.
- `/heal` и `/armour` запрещены против основателя и администраторов более высокого уровня, но разрешают собственному персонажу восстановление для тестов. Заблокированы для погибших, ещё не появившихся, находящихся в режиме наблюдения или активной гонке.
- Здоровье и броня сохраняются непосредственно в аккаунт; если запись в MariaDB или файл аккаунта не прошла, значение в игре и памяти откатывается.
- Команды транспорта проверяют ID, существование машины, виртуальный мир, участников активной гонки и антифлуд **3 секунды** (совместный с `/veh`). Команда без ID работает только если администратор находится в автомобиле.
- `/ahelp` — справка, не журналируется. `/check` журналируется как просмотр.
- Действия над другими игроками учитывают действующую иерархию администрации; собственные инструменты редактирования не предоставляют возможность наказывать высокопоставленного администратора.
- Система не добавляет новые роли, таблицы SQL или файлы пользовательских аккаунтов.

## Ручная проверка после деплоя

Войти под тестовым администратором уровней 1, 2 и 3; проверить `/ahelp`, `/check ID`, успешные `/heal` и `/armour` (и их сохранение после релога), запрет для Veyran и более высокого ранга, отказ без Duty, ошибку при недоступном аудите, ремонт и переворот авто в своём мире, отказ по ID из другого мира и при занятости участником гонки. Проверить сохранение существующих `/veh`, `/weather`, сюжета и PayDay.
