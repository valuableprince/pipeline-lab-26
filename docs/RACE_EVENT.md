# Динамические препятствия гонки

race_event.inc создаёт шесть личных объектов только участнику гонки.
Они расположены на спринтерском участке; RaceEvent_Tick меняет фазу по общему
времени заезда и не отправляет MovePlayerObject повторно при прежней фазе.
Предупреждение перед участком выдаётся один раз на заезд.

Если создание любого объекта не удалось, уже созданные объекты уничтожаются,
а вход в гонку отклоняется. При выходе, отключении и завершении режима личные
объекты очищаются. Общая геометрия трассы обслуживается отдельно race_map.inc
через streamer и виртуальный мир 1800.

Обязателен UAT: проверить движение и столкновения, видимость для участника
и постороннего игрока, повторный заезд, отмену на частичном отказе ресурсов,
выход и переподключение. Статические тесты подтверждают только структуру и
координаты исходного кода, не физическое поведение GTA.
