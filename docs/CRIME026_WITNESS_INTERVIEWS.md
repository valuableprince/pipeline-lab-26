# CRIME-02.6 — NPC-допросы и показания

## Состав этапа

Продолжение CRIME-02.5 в **единственной** ветке
`feat/crime02-solo-contract-core`, PR #111. Цель — сделать вторую стадию
одиночных расследований полноценным взаимодействием с персонажем,
а не прямым выбором финала из меню.

Реализован следующий путь: найти предмет на первой точке → нажать Y →
зафиксировать улику и выбрать способ исследования → приехать ко второму NPC →
нажать Y → выбрать вопрос → прочитать показания → принять финальное решение.
Каждый шаг остаётся доступен при одном игроке онлайн.

## Персонажи, вопросы и последствия

Три сценария используют отдельные реплики:

| Сценарий | Собеседник | Варианты вопросов |
| --- | --- | --- |
| «Пропавший курьер» | Свидетель исчезновения | Сверить показания с уликой / потребовать объяснений |
| «Подозрительный склад» | Работник склада | Проверить журнал охраны / обвинить работника |
| «Сорванная сделка» | Участник переговоров | Уточнить расписку / потребовать согласия |

Содержание показаний привязано к сохранённому сценарию
`scenario_event` и ранее выбранному способу работы с уликой.
Следовательно, разные прохождения могут давать разные факты,
но показания **не меняются случайно после релога**.

Первый вопрос (проверка фактов) при тщательной работе с уликой
и открытом финальном решении даёт **+1 дополнительного доверия**:
максимальное начисление становится +6. В остальных комбинациях
действуют прежние значения +5 / +3 / +2. Денежная награда
не меняется. Награда и доверие по-прежнему начисляются один раз
в общей транзакции.

## Надёжность

При первом разговоре сервер проверяет аккаунт, организацию, стадию 2,
мир и интерьер 0, расстояние 3,5 м, присутствие рядом с NPC,
срок исполнения. Затем в SQL-транзакции устанавливаются
`crime_contracts.interview_question` и `interviewed_at` и
вставляется событие `WITNESS_INTERVIEWED`.

Второй раз допрос не перезаписывается: игрок может повторно прочитать
сохранённые показания. Сервер откажется завершить сценарный контракт
без `interviewed_at > 0`, независимо от состояния окна.
Устаревшие окна контролируются по токену авторизации и ID контракта.
Новых команд и таймеров нет.

## Миграция

Применить **`db/migrations/037_crime_witness_interview.sql`**
после 031–036, один раз на остановленном сервере с резервной копией БД.

Для начатых до обновления сценариев, которые уже находятся на стадии 2,
миграция заполняет `interviewed_at`. Это позволяет завершить старую
миссию без повторного визита. `interview_question=0` означает
прежние показания и **отсутствие нового бонуса доверия**.

При отсутствии версии 037 криминальная подсистема не активируется.
Остальные финансовые/государственные модули не изменяются.

## Автоматические тесты

- `tests/test_crime026_interview.py` — контракты, диалоги,
  ограничения, защита от двойной записи;
- `tests/crime026_mysql_uat.py` — реальная MariaDB:
  нельзя поговорить до стадии 2, нельзя изменить вопрос после записи,
  проверка другой фракции, сохранение после нового подключения,
  бонус доверия +6 и обычное значение +5,
  совместимость с историческими сценариями;
- прежние MariaDB-тесты CRIME-02.1–02.5 и GOV;
- компиляция Pawn/AMX и контроль уникальности ID диалогов.

## Финальная игровая приёмка (позже, вместе со всей системой)

Не требовать ручной установки после каждого этапа. При комплексном
тестировании: выбрать каждый из трёх сценариев, найти улику,
поговорить с NPC двумя способами, сверить запись в журнале,
выплату и изменение доверия, а также восстановление после релога.

**Ограничения:** беседы представлены текстовыми диалогами стандартного
open.mp; озвучка, анимированное поведение, новые модели и
интеллектуальная реакция NPC ещё не реализованы. Координаты
всё ещё подлежат проверке непосредственно в GTA.
