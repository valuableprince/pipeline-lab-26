# Streamer в open.mp

В репозитории зафиксирован include streamer v2.9.6. Бинарный streamer.dll для
Windows либо streamer.so для Linux устанавливается отдельно под архитектуру
сервера и включается через pawn.legacy_plugins. Не заменяйте include без
проверки соответствующего бинарного плагина. Для авторизации также нужен
samp_bcrypt; остальные зависимости описаны в COMMAND_PROCESSOR.md.

race_map.inc один раз создаёт общую динамическую геометрию в виртуальном мире
1800, interior 0. Вход/выход отдельного гонщика не пересоздаёт всю карту;
Streamer_Update обновляет видимость. Частичный отказ создания откатывается.
RaceMap_Shutdown уничтожает общие объекты при завершении режима. Личные
движущиеся препятствия race_event.inc используют другой жизненный цикл.

UAT: проверить загрузку плагина без unknown native, карту у двух гонщиков,
изоляцию обычного мира, поздний вход, выход одного участника, повторный заезд
и перезапуск режима. Компиляция подтверждает сигнатуры, не streaming GTA-клиента.

SHIP-MAP-01: `ship_sf_pier_map.inc` использует тот же streamer в мире 0 / interior 0.
496 объектов создаются один раз в OnGameModeInit, очищаются в OnGameModeExit;
ошибка создания/материала откатывает комплект. По умолчанию пирс отключён до
съёмки берега в GTA. Настройки, реестр моделей, экспорт Pawn и UAT:
[SHIP_SF_PIER_MAP_01.md](SHIP_SF_PIER_MAP_01.md).
