# ADMIN-TOOLS-02 — инструменты администрации Tarkenso RPG

## Команды

| Команда | Мин. уровень | Действие |
|---|---|---|
| `/unmute ID` | 2 + Duty | Снять активную блокировку чата; результат немедленно сохраняется в аккаунт |
| `/history ID` | 2 + Duty | Последние пять записей WARN/MUTE/UNMUTE/KICK/BAN из административного журнала для игрока онлайн |
| `/respawn ID` | 3 + Duty | Вернуть игрока на предусмотренную модом точку появления |
| `/setskin ID skin` | 3 + Duty | Временно установить скин, не меняя постоянную внешность/точку появления |
| `/settime часы минуты` | 3 + Duty | Выставить глобальное время 0–23:0–59; сохраняется для новых спавнов до следующего изменения |
| `/clearchat` | 4 + Duty | Сдвинуть содержимое общего чата пустыми сообщениями; антифлуд 30 секунд |
| `/setvw ID мир` | 4 + Duty | Перенести персонажа в виртуальный мир 0–65535, кроме зарезервированного мира гонок |
| `/setint ID интерьер` | 4 + Duty | Перенести персонажа в интерьер 0–255 |

## Единый справочник

`/ahelp` и `/ahelp 2` показывают список доступных команд (4 на страницу), каждая с тремя полями **Синтаксис / Назначение / Пример**. `/ahelp mute` показывает сведения только о `/mute`. Описания хранятся в одном справочнике `admin_help.inc` (доступ определяется текущими правами), неверные параметры большинства команд направляют к тем же подсказкам. Команды уровня Founder и Event Team не показываются сотрудникам без соответствующих прав.

Например, `/mute` без параметров: `Синтаксис: /mute ID минуты причина`; `Назначение: Заблокировать игроку чат на время`; `Пример: /mute 12 30 Флуд`.

## Ограничения и безопасность

Все команды требуют `/aduty`, действия читают текущие права из `Admin_Require`. Администраторы не могут воздействовать на основателя и администраторов выше себя, кроме допустимых действий над собственным персонажем при тестировании. `/unmute` отклоняет отсутствие активного mute и выполняет откат при ошибке сохранения. Изменение времени, скина, игрока и общего чата журналируется **до** эффекта. При недоступном аудите эффект не выполняется.

Перемещение, респавн и скин запрещены для игроков во время гонок, активного сюжетного пролога, неавторизованных, ещё не появившихся, мёртвых и наблюдающих. Перемещение запрещено из транспорта; администраторы не могут вручную помещать игрока в виртуальный мир гонок. Изменение `/setvw`/`/setint` действует в текущей игровой сессии; при обычном новом появлении используется штатная точка.

Погодные `/event` обновляют сюжетные час и минуты, `/settime` задаёт время независимо от выбранной погоды. После перезапуска время возвращается к 03:17.

Команда `/history` читает существующий файловый `signal_admins/audit.log`; формат журнала не меняется и SQL-миграция не нужна. Отображаются только записи из файлового журнала, когда аккаунт игрока сейчас онлайн. Существующие сведения о наказаниях вне него не реконструируются. `/clearchat` использует серию пустых сообщений; история чата в клиенте физически не удаляется.

## UAT

Проверить права уровней 1–6 и Founder, отсутствие Duty, строгую валидацию ID/часов/скинов/миров, fail-closed аудит и сохранение mute после повторного входа. Проверить отображение /ahelp без неразрешённых команд, сюжет, гонки, новые спавны после /settime и работоспособность существующих /weather, /veh, /mn и PayDay.
