# Управление кораблём: единая команда /ship

Для Tarkenso RPG одна команда открывает главное меню стандартных игровых диалогов open.mp. Старые подкоманды **сохранены для совместимости**, но пользователю их больше не нужно запоминать.

## Главное меню

1. **Общая информация**: модель, состав, координаты, текущий режим движения, наличие LS/SF стоянок и точек выхода, количество записанных портовых манёвров. Просмотр: администратор уровня 2+ на /aduty.
2. **Управление рейсами**: отправление из LS, отправление из SF, остановка судна, сведения о состоянии. Движение выполняется существующим `ShipPort_Command`; без разрешений основателя команды не запускаются.
3. **Визуальный редактор**: открыть top-down редактор корпуса с кнопками сохранения причалов и выходов.
4. **Портовые маршруты**: открыть визуальный редактор с LS OUT / LS IN / SF OUT / SF IN, загрузить один из морских пресетов, экспортировать маршрут. Портовые точки авторизуются и сохраняются внутри редактора.
5. **Наблюдение за кораблём**: открыть существующую камеру `/shipcam`, справа варианты ракурсов. Закрыть ESC/EXIT CAMERA.
6. **Дополнительные инструменты**: собрать грузовой корабль, сохранить, загрузить, экспортировать, освободить блокировку, показать старую справку, очистить несохранённый экземпляр с отдельным подтверждением.

Встроенные действия, меняющие игру, доступны только основателю с `/aduty`. Просмотр и камера — администратору 2+ с `/aduty`. Сервер повторно проверяет права на **каждом** ответе диалога, ID/выбор не дают привилегий. Удаление требует подтверждения и отклоняется, если возле корпуса есть игроки.

## Короткие команды

- `/ship` — основная панель.
- `/shipcam` — камера сразу, если нужен быстрый доступ.
- `/ship stop` — экстренная остановка основателем; без открытия меню.

Для разработчиков продолжают работать все существующие `/ship cargo|create|add|move|turn|set|mark|undo|save|load|export|preset|port|edit|release|clear|run` и `/shipsurf`. **Не запускать `/ship run` с пассажирами**: эта старая тестовая команда телепортирует корабль на первую точку.

## Тесты

Открыть с уровнями 1/2/6; включить/выключить /aduty; проверить основную и вложенные страницы и отмену диалога; отправление только при записанной стоянке; активацию редактора и возврат камеры; независимый /shipcam; сохранить/загрузить; удалить с подтверждением без пассажиров. Сборка Pawn не заменяет проверку диалогов и игрового стриминга.

## Статус

Этот этап находится в отдельной ветке поверх ещё не объединённых этапов корабля. Действия выполняются через имеющиеся Ship Studio / Ship Port / Ship Camera; никаких новых непрерывных таймеров, сканирования берега или поиска пути для меню нет.
