# SHIP-HORN-01 — выбранный гудок для Tarkenso RPG

**Выбран именно второй предложенный трек**: [ship horn very close (Pixabay, 14642)](https://pixabay.com/sound-effects/city-ship-horn-very-close-14642/), автор оригинальной записи указан на странице, продолжительность примерно 5–6 секунд. Pixabay указывает Pixabay Content License. Оригинальная запись этого же звука размещена на [Freesound — 420716](https://freesound.org/people/tierrafilm%40gmail.com/sounds/420716/) под лицензией **CC0**. Аудио не включено в публичный исходный код. Если берёте файл на Freesound, это исходный WAV; для open.mp конвертируйте его в MP3/OGG. Перед использованием проверяйте сведения о файле и лицензии на выбранном источнике.

## Однократная настройка

1. Скачайте выбранный MP3 по ссылке выше через официальную страницу Pixabay (кнопка **Free Download**).
2. Разместите MP3 на собственном сервере со стабильным **прямым HTTPS-адресом** к самому файлу, например на своём веб-хостинге. Не используйте URL страницы Pixabay и не полагайтесь на временную CDN-ссылку для скачивания.
3. Создайте файл `scriptfiles/shipstudio/horn_url.txt` на *игровом* сервере, в нём одна строка — **реальный HTTPS URL загруженного MP3** (или OGG). Не используйте комментарии или пробелы в этом файле. Пути `shipstudio/... ` в коде отсчитываются от каталога `scriptfiles`.
4. Перезапустите игровой режим/сервер. Проверьте сообщение в консоли `[ShipHorn] Configured for the selected Pixabay ship horn.`. Пока URL не задан, **выбранный звук не воспроизводится** — сервер об этом сообщает; подстановка другого звука отключена.

## Поведение

- Успешное начало отхода через меню `/ship` → **Управление рейсами** → отправить из LS/SF запускает гудок **один раз**. Срабатывает и для прямого маршрута из порта, и для маршрута с промежуточными точками.
- Успешное завершение записанного маршрута захода к причалу также подаёт один гудок.
- В том же меню **Подать корабельный гудок** запускает звук вручную по кнопке, без новых команд.
- Звуковой поток предлагается только игрокам рядом с кораблём в основном мире и интерьере 0, радиус 220 игровых единиц, серверный антиспам 12 секунд.
- **Радиостанции и гонки не прерываются:** если пользователь слушает серверное радио или участвует в гонке, гудок ему пропускается. open.mp имеет только один URL-аудиопоток на клиента. Другие внешние аудиомодули могут потребовать дополнительных флагов, если они используют этот же канал.
- Нет таймеров, нового опроса карты и дополнительного поиска коллизий. Один проход по онлайн-игрокам только **в момент события**, а не каждый тик.

## Приёмка

Проверить на клиенте: воспроизведение выбранного MP3 по прямой ссылке; гудок у борта / отсутствие вдали; сохранение радио без прерывания; отправление с/без waypoint, прибытие в LS/SF, повторное нажатие HORN (cooldown); запуск без файла URL, битую/HTML-ссылку; рестарт после настройки; стандартные доступы Founder + /aduty.

Компиляция и текстовые тесты не могут проверить доступность MP3 из клиента и громкость. Звук будет фактически готов к прослушиванию **только после размещения MP3 и настройки URL**.
