# ADMIN-PUNISH-03 — наказания и служебные записи

Требуется **MariaDB schema v9**. Сначала сделать резервную копию БД и остановить игровой сервер, затем применить `db/migrations/009_admin_punish.sql` в phpMyAdmin. Только после этого устанавливать новый AMX и перезапускать open.mp: сервер теперь проверяет наличие записи v9 в `schema_migrations` при старте и **отказывает в запуске** без миграции. Изменения в боевую БД этим PR не применяются.

| Команда | Права | Назначение |
| --- | --- | --- |
| `/ajail ID минуты причина` | 3+, Duty | Тюремный срок 1–43200 минут, MariaDB + аудит |
| `/unjail ID` | 3+, Duty | Раннее освобождение заключённого |
| `/jailinfo ID` | 2+, Duty | Причина и оставшееся время заключения |
| `/warns ID` | 2+, Duty | Последние 5 действующих предупреждений |
| `/unwarn ID номер причина` | 4+, Duty | Снять предупреждение по его SQL-ID |
| `/anote ID текст` | 2+, Duty | Добавить приватную заметку (до 160 символов) |
| `/anotes ID` | 2+, Duty | Последние 5 служебных заметок |
| `/offlineban ник минуты причина` | 5+, Duty | Бан отсутствующего игрока 1–43200 минут; 0 — бессрочно |

Общий формат подсказок доступен через `/ahelp команда`: синтаксис, назначение, пример.

Заключение: база хранит окончание срока как Unix timestamp, так что релог не снимает наказание. Состояние загружается **до первого спавна**, спавн переносится в изолированный `virtual world=27000`, `interior=6`, координаты `264.63,77.57,1001.04` (пилотная точка, требуется внутриигровая проверка интерьера). Каждые 5 секунд сервер проверяет координаты и виртуальный мир. Команды заключённого блокируются (кроме `/help` и `/report`), гонки не принимают заключённых. Смерть и возрождение возвращают в тюрьму. Освобождение выполняется только после подтверждения UPDATE MariaDB.

Предупреждения: существующая команда `/warn` теперь создаёт активную запись в `admin_warnings`; `/unwarn` помечает запись как отозванную, не удаляя историю. Автоматический бан по количеству предупреждений не включён. Заметки доступны только администрации и не выводятся игроку.

Оффлайн-бан: перед записью в существующую таблицу `bans` проверяются ник Founder Veyran, наличие игрока онлайн и административный уровень из **базы**, даже если игрок не в сети. При сбое проверки роли команда отклоняется. Права всех команд проверяются на сервере, аудит пишется **до** изменения данных.

Важно: `/ajail`, `/unjail`, `/jailinfo`, `/warns`, `/unwarn`, `/anote`, `/anotes` работают с **авторизованными игроками онлайн**; `/offlineban` отдельно работает с ником оффлайн. Боевая проверка требует двух клиентов, MariaDB v9 и сценариев повторного входа/смерти/гонки/закрытия журнала.
