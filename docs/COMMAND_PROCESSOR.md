# Процессор команд

Режим использует Pawn.CMD (целевой бинарный пакет 3.4.0-omp) и sscanf v2.13.8.
Исходные includes зафиксированы в gamemodes/includes. Бинарные компоненты
устанавливаются отдельно в components либо через pawn.legacy_plugins согласно
формату конкретного плагина; samp_bcrypt также необходим для входа.

commands.inc регистрирует cmd:-обработчики. OnPlayerCommandReceived выполняет
Guard, авторизацию, ограничения живой TDS-операции, тюрьмы и гонки;
OnPlayerCommandPerformed завершает измерение и сообщает о неизвестной команде.
Право проверяет сама подсистема: Command_ExecuteAdmin передаёт команды в
Admin_Execute, Studio_Command — в редактор зон/контейнеров, /tdstudio — в TDS.
Старого OnPlayerCommandText нет. NPC route editor в этой ветке удалён; команды
/npcroute и /nset не входят в активный интерфейс.

Числовые административные параметры проверяет sscanf. Использование подсказывает
AdminHelp_Usage; отсутствие аргументов не должно выполнять опасное действие.
Сборщики CI и Windows копируют все существующие *.inc и конвертируют UTF-8
в CP1251 для клиента. Результат MySQL-primary сборки — build/compiled.amx.

## Ручная приёмка

- Проверить /help, неизвестную команду и доступ до входа/после входа.
- Проверить пустые и неверные параметры /setadmin, /ban, /mute, /tpcor.
- Проверить /aduty и иерархию цели, ограничения гонки, тюрьмы и живого TDS-ввода.
- Проверить отсутствие повторных регистраций команд и корректную загрузку plugins.

Для отката используйте проверенную пару исходников/AMX и совместимых плагинов;
откат SQL-данных не выполняется заменой compiled.amx.
