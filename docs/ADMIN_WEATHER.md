# Административная погода Tarkenso RPG

Команда `/weather ID` доступна администраторам уровня 2–6 с включённым `/aduty`. Допустимы только целые ID погоды **0–45**.

Пример: `/weather 9` — применить погодный пресет 9 ко всем авторизованным игрокам. Изменение фиксируется в `signal_admins/audit.log` до применения: при ошибке записи изменение отклоняется.

Выбранная погода сохраняется в памяти запущенного сервера и применяется к игрокам после нового спавна. После перезапуска сервера устанавливается пресет 9. Команды `/event fog|night|clear` управляют сюжетными эффектами и при выполнении также сбрасывают погодный пресет на соответствующий сценарию (fog=20; night/clear=9). Если после сценария вызвать `/weather`, изменится погода, но время суток останется сюжетным.

Технические ID и заголовки файлов аккаунтов / уборщика не переименованы ради обратной совместимости. Основное имя игрового сервера — **Tarkenso RPG**, заголовок статистики — **«Статистика персонажа»**.
