# NOTIFY-01 — единый стандарт уведомлений TARKENSO

**Ветка:** `feat/crime02-solo-contract-core`; **PR:** #111.

## Единый стиль

Формат каждого системного сообщения: **[Название системы] Текст**.
Префикс окрашен фирменным цветом, основной текст белый `#FFFFFF`,
успех зелёный `#B6E4B3`, предупреждение красное `#E27E82`,
подсказка серо-голубая `#9FAAB8`. Без декоративных
разделителей из знаков равенства. Длинные результаты и пояснения
передаются отдельными строками без повторения префикса.

## API

Новый модуль `gamemodes/includes/notification_style.inc`,
подключён до игровых компонентов. Контракт:

```pawn
TNotify_Send(playerid, TNOTIFY_WORK, TNOTIFY_SUCCESS,
    "Смена началась.");
TNotify_Send(playerid, TNOTIFY_CRIME, TNOTIFY_WARNING,
    "Контракт просрочен.");
TNotify_All(TNOTIFY_SHIP, TNOTIFY_INFO,
    "Грузовое судно вышло из порта.");
TNotify_Detail(playerid, TNOTIFY_HINT,
    "Для продолжения используйте /crime.");
```

`TNotify_Send` добавляет фирменный префикс и
семантический цвет; `TNotify_All` рассылает событие
всем онлайн-игрокам (без NPC); `TNotify_Detail`
служит для поясняющих строк. Максимальная длина 144
символа, буфер Pawn 145 ячеек с завершающим EOS.

Пользовательский ввод до подстановки в цветные строки
следует нормализовать: недоверенные цветовые токены,
служебные символы или переносы не должны менять UI.

## Интеграции и исключения

Ключевые события переведены в
`payday.inc`, `bond_coupon.inc`,
`ship_notice.inc`, `story_prologue.inc`,
`race_core.inc`, `admin_system.inc`,
`leader_system.inc`, `cleaner_job.inc` и
`crime_reconnect.inc`.

**RP-чат (/me, /do, /try, /b), рация (/r) и диагностические
сообщения не проходят через уведомления**: это отдельные каналы.
Новые системные сообщения должны использовать общий API.
Старые строки в других подсистемах не заменяются автоматически
без отдельного анализа игровых функций и визуального теста.
