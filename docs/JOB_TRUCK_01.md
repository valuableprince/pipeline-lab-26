# JOB-TRUCK-01 — Муниципальная служба

Реализована первая стадия: левый ALT у NPC-диспетчера открывает диалог выбора работы. Сборщик использует прежний механизм смены и сохраняет опыт; водитель доступен с 2 ранга сборщика (20 опыта). Одновременно две специализации недоступны. При выходе с сервера и возрождении водительская смена прекращается, прогресс сборщика сохраняется без изменений.

Для водителя команда `/orders` показывает контейнеры с суммой `bin_units + overflow_units` не менее 60, номер из `cleaner_containers.container_id`, название зоны и заполненность из уже загруженных данных MariaDB. Выбор устанавливает личную метку на карте; повторная проверка по постоянному ID и заполнению исключает устаревшие строки. Контейнеры ниже порога не показываются. Новые контейнеры автоматически появляются в списке после сохранения редактором, без ручного назначения района.

Географическая принадлежность вычисляется прямоугольными зонами Fort Carson, Las Payasadas и Las Barrancas; вне них выводится `Bone County / вне зон`. Границы зон ориентировочные и требуют UAT, в дальнейшем их следует хранить в НСИ/БД как многоугольники, чтобы не приписывать неверное название близлежащим местам.

**Это не реализует вывоз или резервирование заказа.** Исполнение, выдача мусоровоза, проверка подъезда задом, анимированное опрокидывание и поштучная погрузка мешков относятся к JOB-TRUCK-02/03, разгрузка на заводе — к следующему этапу. Никакого автоматического вывоза не добавлено. Заказы пока динамически вычисляются по контейнерам, а не хранятся в собственной таблице.

Ручная проверка: ранг 1 не может выбрать водителя; ранг 2 может; меню сборщика запускает прежнюю смену; `/orders` недоступна неводителю; полный контейнер появляется в списке; выбор помечает карту; после опустошения устаревший заказ не принимается; выход из игры очищает смену и метку.

## Таблица заказов и предварительная оплата

`/orders` использует `DIALOG_STYLE_TABLIST_HEADERS` с колонками «Контейнер», «Место», «Заполнение», «Оплата». Для заполненных контейнеров (от 60/100) показывается **расчётная**, ещё не выплачиваемая стоимость: по $10 за единицу содержимого контейнера и по $20 за единицу на внешней площадке. Примеры: 60/100 = $600, 80/100 = $1000, 100/100 = $1400. Фактическое начисление после успешной разгрузки на заводе — задача следующих этапов. Значения можно будет сбалансировать после тестирования экономики.
