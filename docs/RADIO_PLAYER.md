# RADIO-01 — игровое радио TARKENSO

Команда `/play` открывает единый обычный список радиостанций без деления на категории.
После выбора станция включается индивидуально у игрока вызовом
`PlayAudioStreamForPlayer`; второй выбор заменяет текущий поток.
Нижняя строка «Выключить радио» вызывает `Radio_Stop`.
Список доступен после авторизации и вне гоночных событий/административного заключения.

## Конфликты и жизненный цикл

- `Radio_Stop` останавливает поток, только если он был запущен этим модулем.
- При вступлении в гонку персональное радио выключается после успешного
  создания гоночной машины: музыкальная система гонок управляет своим потоком.
- Выход из гонки не включает старое радио автоматически.
- При отключении и новом подключении состояние сбрасывается.
- Сервер не ретранслирует и не кеширует сторонние аудиопотоки.
  Для публичного использования проверьте условия правообладателей и
  допустимость интеграции станций в игру.

## Ручная проверка (UAT)

1. Авторизоваться, выполнить `/play`, увидеть десять радиостанций и
   «Выключить радио» в конце списка.
2. Поочерёдно выбрать каждую станцию, проверить фактический звук и отсутствие
   ошибок в клиенте (особенно AAC у Radio Record).
3. Переключить станции без перезахода, затем повторно выбрать ту же станцию.
4. Нажать «Выключить радио»; убедиться, что звук прекратился. Отмена
   диалога не должна менять текущий поток.
5. Запустить обычное радио, вступить в гонку, дождаться гоночной музыки,
   выйти из гонки. Обычное радио не должно мешать гоночному.
6. Переподключиться: радио не должно стартовать автоматически.
7. Проверить отсутствие доступа к команде до авторизации и во время гонки.
